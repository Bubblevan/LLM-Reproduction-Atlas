# Reproduction matrix

> **REP invariant:** A REP represents a concrete, independently completable learning/reproduction experiment.

REP coverage requires evidence from a dedicated reproduction repository, a learning/reimplementation coursework repository, or an explicitly isolated reproduction extension. A formal production/research project that happens to contain a related mechanism cannot establish REP Coverage. In this registry, coverage evidence comes only from eligible learning/reproduction homes such as CS336-A1 and CS336-A5.

Source baseline: a492338499a9381f1714ecda8c802684e0556d3e; audit date: 2026-09-29. Source paths are pinned to that revision. Priority reflects this Atlas owner’s learning order, not universal scientific importance. A paper link is a study target, not a claim that source code reproduces the complete paper.
