## REP invariant

> A REP represents a concrete, independently completable learning/reproduction experiment.

Coverage may be established by a dedicated reproduction repository, a coursework repository whose purpose is learning/reimplementation, or an explicitly isolated reproduction extension.

**Formal-project implementation status is not REP completion evidence.** Production/research project code cannot produce SCAFFOLDED, PARTIAL_EXISTING, COVERED_EXISTING or SUPERSEDED for an Atlas REP. In this registry, crosswalk coverage evidence is restricted to CS336-A1 and CS336-A5.
